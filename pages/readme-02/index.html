rcx02

recursive real-time youtube worm / 0-view slop installation

what it is

a self-feeding video installation that watches itself watching YouTube. uses OCR to read text from its own display, searches YouTube for short videos matching those words, downloads and plays them back—where they get read again, continuing indefinitely.

the result is a live window into whatever is actually being uploaded to YouTube in real-time: 0-view videos, global content drift, algorithmic noise. first installed at Columbia College Chicago Manifest 2024.

the loop

camera → OCR (Keras) → extract words → YouTube search ↓ find short video (<60s) → download → background subtraction ↓ play overlaid → new text appears → loop continues ┌──────────────────────────────────┐ ▼ │ DISPLAY → OCR → SEARCH → DOWNLOAD → PLAY

physical installation

widescreen TV. styrofoam figure with webcam eyes watches the screen. second webcam points down at bananagram tiles on a desk—audience can rearrange letters to steer the worm. what the figure sees becomes the feedback background.

notes

the worm tends to find slop: AI-generated content, test uploads, surveillance footage. language drift follows the sun—the installation cycles through global upload patterns as the day progresses.
