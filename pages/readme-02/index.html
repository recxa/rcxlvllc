rcx02

algorithmic installation

Overview

A generative audiovisual installation exploring emergent patterns and procedural aesthetics. Designed for immersive gallery contexts with an "underground" experimental sensibility.

Concept

The piece generates continuous streams of audio and visual content through algorithmic processes. No two moments are identical. The system responds to time-of-day, accumulated runtime, and subtle environmental factors.

Technical Approach

  • Real-time audio synthesis with stochastic parameter modulation
  • Visual output driven by the same data streams as audio
  • Long-form generative composition — designed for hours of continuous playback
  • Minimal human intervention once running

Installation Requirements

  • Projection surface or large display
  • Stereo or multichannel audio system
  • Dedicated computer running the system
  • Dark or controlled lighting environment

Development Status

Multiple iterations exist. VOD documentation available. Potential for live-streamed versions under consideration.
