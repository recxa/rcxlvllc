rcx03

cellular audio engine

A Game of Life-based audio system built in Max/MSP and Processing. The cellular automata grid directly controls audio parameters — horizontal position affects pitch, vertical affects timbre, and cell density controls amplitude. Simple concept, cohesive execution.

An interactive drawing system combining cellular automata with generative layering. Paint cells onto the canvas, watch them evolve according to Game of Life rules, then save layers and start fresh. rcx05

hybrid visualizer

A Processing and TouchDesigner hybrid for real-time audio-reactive visuals. The aesthetic embraces digital artifacts — pixelation, feedback loops, color banding. Audio analysis drives visual parameters through OSC communication between environments. Designed for live VJ performance.
