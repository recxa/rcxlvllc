rcx03

cellular audio engine

Overview

A Game of Life-based audio plugin built in Max/MSP and Processing. Simple concept, cohesive execution. The cellular automata grid directly controls audio parameters.

How It Works

  • 2D grid of cells following Conway's Game of Life rules
  • Each cell's state maps to audio parameters (pitch, amplitude, filter)
  • Grid evolution creates evolving, organic sound textures
  • User can seed initial patterns or let randomness guide

Audio Mapping

The grid is divided into regions, each controlling different aspects of the sound. Horizontal position affects pitch. Vertical position affects timbre. Cell density in a region affects amplitude.

Controls

  • Click to toggle cells
  • Space — pause/resume evolution
  • C — clear grid
  • R — randomize
  • Arrow keys — adjust evolution speed

Development Status

Functional prototype. Needs cleanup and extended documentation.
