r c x 0 3 game of life spectral filter ================================================================================ rcx03 is a prototype for a spectral filter controlled by Conway's Game of Life. a 32x32 grid of cells maps directly to FFT bins—alive cells pass audio through, dead cells gate it out. the cellular automaton evolves, and the frequency spectrum evolves with it. it functions as both a filter and a sequencer depending on mode: scanning mode sweeps a slice through the grid like a playhead, while full-spectrum mode uses the entire grid as a static (or evolving) comb-like spectral mask. Processing handles the Game of Life simulation and UI; Max/MSP handles the audio. ================================================================================ HOW IT WORKS ================================================================================ THE GRID ────────────────────────────────────────────────────────────────────── 32 x 32 cells = 1024 cells total, mapped 1:1 to 1024 FFT bins. frequency mapping is logarithmic (20 Hz – 20 kHz), so the grid covers the audible spectrum perceptually—low frequencies at one end, highs at the other, spaced by octaves rather than linearly. cell alive → that frequency bin passes through cell dead → that frequency bin is gated/silent the grid wraps toroidally (edges connect), so patterns can flow continuously without hitting walls. MODES ────────────────────────────────────────────────────────────────────── SCANNING MODE (sequencer-like) a playhead sweeps through the grid. each frame, one slice is sent as the spectral mask. the yellow highlight shows which slice is currently active. creates rhythmic, evolving spectral patterns. FULL-SPECTRUM MODE (comb-like) the entire 32x32 grid used as spectral mask simultaneously. creates a comb-filter-like effect—many frequency bands gated on/off across the spectrum at once. ================================================================================ CONTROLS ================================================================================ LMB drag paint cells alive (white) RMB drag paint cells dead (black) [▶] play/pause automatic generation advancement [I] immortal mode (manual stepping only) [NEXT] manually advance one generation [RAND] LMB: randomize grid / RMB: clear grid [MIX] wet/dry slider (default: 0.8) ================================================================================ NOTES ================================================================================ · classic Game of Life patterns translate to spectral behaviors: - gliders = sweeping frequency bands - oscillators = rhythmic spectral pulses - still lifes = static EQ curves - chaos = dense, evolving textures · phase is preserved during gating, so the output stays coherent · · · rcx03 is a prototype. the concept: what if a cellular automaton was a filter? what if Conway's rules shaped your frequency spectrum? ================================================================================ prototype uses: processing, max/msp, osc ~

rcx03

game of life spectral filter

what it is

a spectral filter controlled by Conway's Game of Life. 32x32 grid of cells maps directly to 1024 FFT bins—alive cells pass audio through, dead cells gate it out. the cellular automaton evolves, and the frequency spectrum evolves with it.

functions as both filter and sequencer: scanning mode sweeps a slice like a playhead, full-spectrum mode uses the entire grid as a comb-like spectral mask.

the grid

32×32 = 1024 cells mapped 1:1 to FFT bins. frequency mapping is logarithmic (20Hz–20kHz), covering the audible spectrum perceptually. grid wraps toroidally—patterns flow continuously without hitting walls.

controls

  • LMB drag — paint cells alive
  • RMB drag — paint cells dead
  • ▶ — play/pause generation advancement
  • I — immortal mode (manual stepping)
  • NEXT — advance one generation
  • RAND — randomize (LMB) / clear (RMB)
  • MIX — wet/dry (default 0.8)

notes

Game of Life patterns become spectral behaviors: gliders = sweeping bands, oscillators = rhythmic pulses, still lifes = static EQ, chaos = dense textures. phase is preserved during gating.
