r c x 0 5 noclip depth-based video compositing ================================================================================ rcx05 is a video compositing system that overlays multiple videos in 3D space using AI-extracted depth maps. on a pixel-by-pixel, frame-by- frame basis, the system shows whichever video is "closest" at that point—as if the videos were stacked in depth and you're seeing through to whatever's in front. the result: objects from different videos appear to coexist and pass through each other based on their actual spatial depth. example: two clips from a stationary camera at an intersection, shot at different times. cars from both clips appear simultaneously, driving "through" each other—each visible when it's the closest thing at those pixels. this is a demonstration of a video effect, with the goal of eventually becoming a plugin for video editing software. ================================================================================ HOW IT WORKS ================================================================================ THE CONCEPT ────────────────────────────────────────────────────────────────────── 1. start with multiple video clips (ideally same camera angle) 2. extract depth maps for each video using AI (currently via Runway.ai) 3. play all videos simultaneously 4. for each pixel, each frame: compare depth values across all videos show the pixel from whichever video has the closest depth 5. result: videos composited as if they exist in the same 3D space COMPOSITION METHODS ────────────────────────────────────────────────────────────────────── FRONT-ONLY show whichever video is closest at each pixel (the default "noclip" effect) BACK-ONLY show whichever video is furthest at each pixel THRESHOLD user-controlled depth range—only show pixels within a specific depth band SCANNING animated depth threshold that cycles through the depth range, revealing layers progressively ================================================================================ IMPLEMENTATIONS ================================================================================ PROCESSING (prototype) ────────────────────────────────────────────────────────────────────── fuller prototype demonstrating multiple composition methods. includes interactive threshold control, grid visualization, frame-by-frame recording. limitations: inefficient, hard-coded to low resolution, frame alignment issues between source and depth videos. TOUCHDESIGNER (simplified) ────────────────────────────────────────────────────────────────────── simplified version implementing only front-only method. can run at any resolution, incorporate into other patches. this is the cleaner, more practical implementation. ================================================================================ NOTES ================================================================================ · the effect works best when videos share a camera angle · depth extraction quality matters—AI estimation isn't perfect · "noclip" comes from the video game cheat that lets you pass through walls · · · rcx05 asks: what if you could stack videos in depth and see through to whatever's in front? this is the experiment. ================================================================================ ongoing uses: processing, touchdesigner, runway.ai ~

rcx05

noclip — depth-based video compositing

what it is

a video compositing system that overlays multiple videos in 3D space using AI-extracted depth maps. pixel-by-pixel, frame-by-frame, the system shows whichever video is "closest"—as if videos were stacked in depth and you see through to whatever's in front.

example: two clips from a stationary camera at an intersection, shot at different times. cars from both appear simultaneously, driving "through" each other based on which is closest at each pixel.

how it works

1. multiple video clips (same camera angle ideal) 2. extract depth maps via AI (Runway.ai) 3. play all videos simultaneously 4. per pixel, per frame: show closest depth 5. result: videos in same 3D space

composition methods

FRONT-ONLY: closest video wins (default noclip effect). BACK-ONLY: furthest video wins. THRESHOLD: only show specific depth band. SCANNING: animated threshold reveals layers progressively.

implementations

Processing prototype: multiple methods, interactive threshold, grid visualization. TouchDesigner version: simplified front-only, any resolution, practical for integration.

uses: processing, touchdesigner, runway.ai
