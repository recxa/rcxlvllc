rcx05

hybrid visualizer

Overview

A Processing and TouchDesigner hybrid system for real-time audio-reactive visuals. Designed for live performance and VJ contexts.

Architecture

  • Processing handles generative geometry and particle systems
  • TouchDesigner manages compositing, effects, and output routing
  • OSC communication between the two environments
  • Audio analysis drives parameters in both systems

Visual Language

The aesthetic leans into digital artifacts — pixelation, feedback loops, color banding. Not trying to hide the computational nature of the visuals. Embraces the glitch.

Audio Reactivity

  • Frequency bands mapped to different visual parameters
  • Onset detection triggers discrete events
  • RMS amplitude controls overall intensity
  • Spectral centroid affects color temperature

Development Status

One demo posted. Additional demo in progress. Code not yet packaged for distribution.
