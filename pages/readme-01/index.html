rcx01

explorative loop sampler

Overview

A keyboard-driven audio performance system designed for real-time loop manipulation and explorative sampling. Built for live performance contexts where traditional DAW workflows feel too rigid.

Core Concepts

  • Non-linear loop navigation — jump between segments without timeline constraints
  • Keyboard-first interface — all controls mapped to single keypresses
  • Layered recording — stack loops with independent playback states
  • Destructive-by-design — embrace impermanence in live performance

Technical Details

Built in Max/MSP with custom abstractions for buffer manipulation and MIDI mapping. Uses a state machine architecture for managing loop transitions and recording modes.

Development Status

Alpha stage. Core functionality complete. Playtest studies conducted with small groups. Documentation in progress.

Controls

  • Number keys (1-9) — select loop slots
  • Space — toggle playback
  • R — arm recording
  • Backspace — clear current slot
  • Arrow keys — nudge loop boundaries
