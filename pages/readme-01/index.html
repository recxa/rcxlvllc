r c x 0 1 dynamic loop sampler ================================================================================ rcx01 is a loop sampler built for real-time exploration and manipulation. it combines a Processing front-end with a SuperCollider audio engine, connected via OSC. tempo is controlled through ship physics rather than a slider. samples are organized across two axes. everything is keyboard- driven and designed to reward intuition over manual precision. the instrument is built around the idea that parameters like tempo and sample selection can be terrain to move through rather than values to set. it's useful for solo beatmaking, live performance, or jamming with others who may not have experience with traditional production tools—the controls are immediate enough that someone unfamiliar with DAWs can still be at the wheel of the beat. ================================================================================ ARCHITECTURE ================================================================================ ┌─────────────────────┐ OSC ┌─────────────────────────┐ │ │ ──────────────────▶ │ │ │ Processing (pde/) │ │ SuperCollider (.scd) │ │ │ │ │ │ - UI rendering │ /bpm, /dex, /rev, │ - audio playback │ │ - keyboard input │ /jump, /rec, etc. │ - recording │ │ - ship physics │ │ - effects │ │ - visual feedback │ │ - deck management │ │ │ ◀────────────────── │ │ └─────────────────────┘ waveform data └─────────────────────────┘ ================================================================================ THE ENGINE ================================================================================ DECKS & BUFFERS ────────────────────────────────────────────────────────────────────────── audio is organized into Decks. each Deck holds 4 interchangeable buffers— think of them as 4 variations of the same musical idea. there are 8 Decks total: the first 4 are assigned to the X-axis sampler, the next 4 to the Y-axis sampler. Deck 0 ──▶ [ buf0 | buf1 | buf2 | buf3 ] ─┐ Deck 1 ──▶ [ buf0 | buf1 | buf2 | buf3 ] │ X-axis Deck 2 ──▶ [ buf0 | buf1 | buf2 | buf3 ] │ samplers Deck 3 ──▶ [ buf0 | buf1 | buf2 | buf3 ] ─┘ Deck 4 ──▶ [ buf0 | buf1 | buf2 | buf3 ] ─┐ Deck 5 ──▶ [ buf0 | buf1 | buf2 | buf3 ] │ Y-axis Deck 6 ──▶ [ buf0 | buf1 | buf2 | buf3 ] │ samplers Deck 7 ──▶ [ buf0 | buf1 | buf2 | buf3 ] ─┘ PHASOR-DRIVEN PLAYBACK ────────────────────────────────────────────────────────────────────────── a global phasor runs continuously, synced to the current BPM. this phasor (ranging 0–4, representing 4 beats) drives all sample playback. every sampler reads its buffer position from this phasor, so all loops stay locked together regardless of which buffers are active. because playback is phasor-driven rather than trigger-driven, switching buffers mid-loop is seamless—the new buffer picks up at the same phase position. ================================================================================ CONTROLS ================================================================================ SHIP / TEMPO ────────────────────────────────────────────────────────────────────────── ↑ thrust forward (accelerate in facing direction) ← → rotate ship left/right SPACE brake (kill velocity) tempo is derived from the ship's position on the 2D plane. rcx01

dynamic loop sampler

what it is

a loop sampler built for real-time exploration and manipulation. Processing front-end, SuperCollider audio engine, connected via OSC. tempo is controlled through ship physics rather than a slider. samples organized across two axes. everything keyboard-driven.

the instrument is built around the idea that parameters like tempo and sample selection can be terrain to move through rather than values to set. useful for solo beatmaking, live performance, or jamming with others who may not have DAW experience.

architecture

┌─────────────────────┐ OSC ┌─────────────────────────┐ │ Processing (pde/) │ ──────────────────▶ │ SuperCollider (.scd) │ │ - UI rendering │ /bpm, /dex, /rev, │ - audio playback │ │ - keyboard input │ /jump, /rec, etc. │ - recording │ │ - ship physics │ ◀────────────────── │ - effects │ └─────────────────────┘ waveform data └─────────────────────────┘

the engine

audio organized into 8 Decks, each with 4 interchangeable buffers. first 4 Decks = X-axis sampler, next 4 = Y-axis sampler. a global phasor (0–4, representing 4 beats) drives all playback, so switching buffers mid-loop is seamless.

controls

  • ↑ ← → — thrust/rotate ship (tempo via position)
  • SPACE — brake
  • 1-4 / Q-V — main matrix (deck/buffer selection)
  • 5-8 / T-, — alt matrix (16 jump points)
  • TAB — recording mode
  • ENTER — prime/confirm recording
  • [ ] — toggle X/Y reverse
  • - = — mute toggles
