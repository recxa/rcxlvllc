lifebrush

Overview

An interactive drawing system combining cellular automata with generative layering. Paint cells onto a canvas, watch them evolve according to Conway's Game of Life rules, then save the state and start fresh with a new layer.

How It Works

Drag to paint cells. After painting enough cells (threshold of 20), the Game of Life rules are applied. Click to save your current drawing as a frozen layer and start fresh with a new random resolution and color.

Controls

  • drag — paint cells onto the grid
  • left click — save layer, reset with new resolution
  • right click — randomize color, reset
  • space — randomize color, reset
  • ↑ — advance all layers one generation
  • enter — download canvas as PNG
  • delete — full reset (clear all layers)

Concept

Lifebrush treats the Game of Life not as a simulation to observe, but as a drawing medium. The randomized resolution on each reset creates visual variation — sometimes you're painting with large blocks, sometimes fine pixels. Layers accumulate like geological strata.

Technical Details

Built with p5.js. State persists across page navigation within the site. The canvas is divided into a grid, with each cell tracked in a 2D array. Evolution follows standard Conway rules with toroidal wrapping.
